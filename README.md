# AI Architect · Micro-PoC

Public architecture portfolio for **Arik Rozen** (AI Architect).

**Positioning:** architecture before tools. Vendor-neutral Micro-PoCs in ≤3 weeks for CEOs and operators who need autonomous or partly-autonomous systems without pilot theater.

This repo holds:

- Architecture Decision Records (ADRs) you can inspect
- A Micro-PoC scaffold (definition of done, no client secrets)
- A short agent / NHI governance checklist

No client data. No fake logos. Proof via method, not brand cover.
